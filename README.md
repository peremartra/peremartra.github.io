# peremartra.github.io

Personal website of Pere Martra, served by GitHub Pages at https://peremartra.github.io/.

Built by GitHub Pages with Jekyll, no theme and no plugins. `_layouts/default.html` holds the shared header, navigation and footer; pages are `index.html`, `books/index.html` and `books/rearchitecting-llms/index.md`; styles live in `assets/css/style.css`.

Local preview: `jekyll serve` (with the `github-pages` gem installed), then open http://localhost:4000/.
